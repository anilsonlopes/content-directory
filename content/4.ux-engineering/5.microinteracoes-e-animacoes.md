Microinterações são respostas pequenas e focadas que comunicam mudança de estado, resultado de uma ação ou relação entre elementos. Movimento útil explica o que aconteceu; movimento decorativo apenas consome atenção.

## Funções do movimento

- confirmar uma ação;
- indicar origem e destino de uma mudança;
- preservar contexto durante transições;
- direcionar atenção para informação nova;
- comunicar carregamento, progresso, sucesso ou erro;
- melhorar a percepção de continuidade.

## Implementação

Para transições simples, prefira CSS. Use JavaScript ou bibliotecas especializadas quando houver sequenciamento, gestos ou controle de estado que justifiquem o custo.

Priorize propriedades como `transform` e `opacity`, evite trabalho excessivo de layout e meça o efeito nas métricas de desempenho. Uma animação não deve atrasar a conclusão da tarefa nem bloquear interação sem necessidade.

## Movimento acessível

Respeite a preferência do sistema:

```css
@media (prefers-reduced-motion: reduce) {
  *, *::before, *::after {
    scroll-behavior: auto !important;
    animation-duration: 0.01ms !important;
    animation-iteration-count: 1 !important;
    transition-duration: 0.01ms !important;
  }
}
```

Redução de movimento não precisa significar remoção de todo feedback. Substitua deslocamentos intensos por mudanças discretas e preserve a informação transmitida.

## Checklist

- [ ] A animação possui uma função compreensível.
- [ ] O estado final independe da animação para ser entendido.
- [ ] Não provoca mudança inesperada de layout.
- [ ] Continua utilizável com movimento reduzido.
- [ ] Não compromete resposta, bateria ou Core Web Vitals.
