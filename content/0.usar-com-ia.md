title: Usar com IA
description: Como conectar o content-directory ao seu assistente de IA pelo servidor MCP, para que ele consulte os posts durante a conversa.

O content-directory também responde a assistentes de IA. O site expõe um servidor [MCP](https://modelcontextprotocol.io) em `https://content-directory.quila.dev/mcp`, por HTTP e sem autenticação. Com ele conectado, o assistente lista as páginas da base, lê as que tratam do seu pedido e responde a partir do que está escrito aqui.

## Conectar um editor ou agente

### Claude Code

```bash
claude mcp add --transport http content-directory https://content-directory.quila.dev/mcp
```

O comando registra o servidor só no projeto atual. Para ele valer em todos os projetos, acrescente `--scope user`:

```bash
claude mcp add --scope user --transport http content-directory https://content-directory.quila.dev/mcp
```

### Cursor

Crie ou edite o arquivo `.cursor/mcp.json` na raiz do projeto:

```json [.cursor/mcp.json]
{
  "mcpServers": {
    "content-directory": {
      "type": "http",
      "url": "https://content-directory.quila.dev/mcp"
    }
  }
}
```

### VS Code

Crie ou edite o arquivo `.vscode/mcp.json` na raiz do projeto:

```json [.vscode/mcp.json]
{
  "servers": {
    "content-directory": {
      "type": "http",
      "url": "https://content-directory.quila.dev/mcp"
    }
  }
}
```

## Conectar um cliente de chat

Nos clientes de chat, o servidor entra como um conector personalizado. Os nomes dos menus mudam com frequência; se algum passo não bater com a sua tela, siga a documentação oficial indicada em cada seção.

### Claude

Vale para o claude.ai e para o Claude Desktop. No plano gratuito, o limite é de um conector personalizado.

1. Abra **Customize > Connectors**.
2. Clique em **Add** e escolha adicionar um conector personalizado (**Add custom connector**).
3. Dê o nome `content-directory` e informe a URL `https://content-directory.quila.dev/mcp`.
4. Em **Authentication**, escolha **No sign in** e conclua em **Add**.
5. Na conversa, abra o botão **+**, entre em **Connectors** e ative o conector.

Em planos Team e Enterprise, quem adiciona o conector é o administrador da organização; os membros só o conectam depois.

Documentação oficial: [Get started with custom connectors using remote MCP](https://support.claude.com/en/articles/11175166-getting-started-with-custom-connectors-using-remote-mcp).

### ChatGPT

Vale para o ChatGPT na web.

1. Abra [chatgpt.com/plugins](https://chatgpt.com/plugins).
2. Clique no botão de adicionar e escolha **Add custom MCP server**.
3. Dê o nome `content-directory` e, em **Server URL**, informe `https://content-directory.quila.dev/mcp`.
4. Na autenticação, escolha **No authentication**.
5. Leia o aviso de risco, confirme e clique em **Create as a plugin**.
6. Instale o plugin criado. Na conversa, digite `@` e selecione `content-directory`.

Workspaces de empresa podem restringir a adição de servidores MCP.

Documentação oficial: [Add custom MCP server](https://developers.openai.com/api/docs/guides/developer-mode).

## O que o servidor oferece

O servidor tem duas tools, e as duas só leem conteúdo:

| Tool | O que faz |
|---|---|
| `list-pages` | Lista título, caminho, descrição e URL de todas as páginas. |
| `get-page` | Devolve o Markdown completo de uma página pelo caminho. |

O fluxo esperado é o assistente chamar `list-pages` para achar as páginas do assunto, ler cada uma com `get-page` e citar a URL das páginas usadas na resposta.

## Exemplos de pedidos

- "Revisa a acessibilidade deste formulário com base no content-directory."
- "Esta página está lenta. O que o content-directory recomenda para imagens e JavaScript?"
- "Como conduzir uma entrevista de discovery?"
- "Preciso documentar esta decisão de arquitetura. Qual formato o content-directory sugere?"
- "O que o content-directory diz sobre hosting verde?"

::tip
Citar o nome "content-directory" no pedido ajuda o assistente a acionar o servidor em vez de responder de memória.
::

::note
Os textos da base estão em domínio público ([CC0 1.0](https://github.com/anilsonlopes/content-directory/blob/main/LICENSE)). O assistente pode complementar a resposta com conhecimento próprio; peça que ele cite a página usada para você distinguir o que veio da base do que é complemento.
::
